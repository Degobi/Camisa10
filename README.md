# Camisa 10

Jogo de carreira de futebol para celular (deitado), feito em Unity 6 (6000.6.4f1).

## Como abrir
1. Clone o repositório (ou use o GitHub Desktop).
2. No Unity Hub: **Add > Add project from disk** e escolha a pasta clonada.
3. Abra o projeto e aperte **Play**. A cena e a aba Game (1920x1080) são configuradas sozinhas.

Para atualizar depois: `git pull` (ou "Fetch/Pull" no GitHub Desktop) com a Unity fechada ou em segundo plano.

Build Android: menu **Camisa 10 > Configurar build Android**, depois **File > Build Profiles > Build**.
